# 가정과 근거 수준

이 시뮬레이션의 수치는 대부분 **가정치**입니다. 실측 자료나 공개 통계에서 가져온 값이 아닙니다.
가정을 숨기지 않고 드러내는 이유는, 도구 효과가 "누가 정한 숫자"인지 설명할 수 있어야 하기 때문입니다.

## 업무 비용 모델 (앱에서 수정 가능)

| 항목 | 기본값 | 근거 수준 | 쓰이는 곳 |
|---|---|---|---|
| 견적서 필드 1개 확인·입력 시간 | 1.2분 | 가정치. 직접 근거 없음 (순수 타이핑은 몇 초 수준이고, 이 값은 찾기와 확인을 포함) | 수작업 견적 입력 시간 |
| 필드 1개 오입력 확률 | 2% | 가정치. 공개 연구 범위(필드별 0.5~6.4%) 안이지만 의료 기록 전사 연구라 분야가 다름 | 단가·납기·결제조건 오입력 |
| 환산 필요 필드 추가 오류 확률 | 6% | 가정치 | USD 환율 착오, VAT·포장단위 착오 |
| 비교표 작성·검토 고정 시간 | 25분 | 가정치 | 견적 비교 1건당 (도구 사용 시 40%) |
| 도구 결과 검토 시간 | 견적 1건당 2.5분 | 가정치 | 도구 사용 시 원문 근거 확인 |
| 정산 불일치 재작업 | 50분 | 가정치 | 발주 단가 오류가 정산에서 발견될 때 |
| 월간 실적 보고 수작업 | 150분 | 가정치 | 월말 보고서 작성 (도구 없음) |
| 보고서 초안 검토·코멘트 | 35분 | 가정치 | 월간 보고 도구 사용 시 |
| 일상 업무(미팅, 문의 대응 등) | 하루 3~6건, 건당 15~90분 | 가정치 | 담당자 업무 부하 |
| 납기 지연 수작업 파악 | 15분 (예정일 당일 미입고를 보고 앎) | 가정치 | 납기 독촉 업무 |
| 납기 위험 알림 확인 | 5분 (예정일 3영업일 전 감지) | 가정치 | 납기 위험 도구 사용 시 |
| 납기 독촉·조율 | 30분, 성공 확률 65%, 남은 시간의 절반까지 만회 | 가정치 | 독촉 결과 입고일 조정 |
| 일일 근무시간 | 480분 | 일반적인 8시간 근무 | 담당자 하루 용량 |

숙련도 보정: 시간은 숙련도 0일 때 1.4배, 100일 때 0.8배. 오류율은 숙련도 0일 때 1.5배, 100일 때 0.5배 (가정치).

## 시장·기업

### 손익 구조 (영업이익률 약 5% 목표)

| 항목 | 값 | 매출 대비 | 근거 수준 |
|---|---|---|---|
| 판매가 | 세트당 4,500원 | 100% | 가상 값 |
| 구매팀이 사는 원료 5종 | 세트당 약 575원 (시세에 따라 변동) | 약 13% | 가상 값 |
| 기타 원재료·부자재 | 세트당 1,660원 | 약 37% | 가정치. 떡, 어묵, 소스 원료 등 구매팀 관찰 범위 밖 |
| 고정비 (인건비, 제조 경비, 판관비) | 하루 810만 원 | 약 45% | 가정치 |
| 영업이익률 | 시드에 따라 연 3~6.5%, 분기별로는 마이너스도 나옴 | 약 5% | 목표치는 아래 공개 자료 기준 |

목표 영업이익률 근거: 국내 상장 식품기업 16곳 평균 영업이익률이 2022년 4.5%, 2023년 5.2%, 2024년 6.3%라는 보도가 있다 ([데일리안, 2024년 실적](https://www.dailian.co.kr/news/view/1472440/), [데일리안, 2022년 실적](https://www.dailian.co.kr/news/view/1205625/)). 검색 요약으로 확인했고 원문 표는 열어 보지 못했다. 원료 비중과 고정비 비중은 이 목표에 맞춘 가정치이며 실제 식품기업의 비용 구조를 확인한 값이 아니다.

단순화한 부분: 법인세, 설비투자, 감가상각을 따로 다루지 않고, 기타 원재료는 쓰는 날 바로 현금으로 지급한다고 본다.

## 근무 달력 (실시간 모드)

- 근무 09:00~18:00, 점심시간 12:00~13:00 (실근무 8시간). 12시에 걸치는 업무는 점심 전후로 나뉜다. 주말과 공휴일은 쉰다. 영업일 09:00이 되면 그날 업무를 계산한다.
- 공휴일 목록(`src/sim/calendar.ts`)은 2026-11-03에 웹 검색으로 정리했다. 참고한 곳: [2026년 대체공휴일 기사(비건뉴스)](https://www.vegannews.co.kr/news/article.html?no=385759), [2026년 6월 3일 임시공휴일 기사(위키트리)](https://www.wikitree.co.kr/articles/1098048), [2027년 개천절·한글날 대체공휴일 기사(비건뉴스)](https://www.vegannews.co.kr/mobile/article.html?no=388618), [한국천문연구원 2027년 월력](https://astro.kasi.re.kr/kor/life/post/calendarData?year=2027). 검색 요약으로 확인했고 원문은 열어 보지 못했다.
- 2027-02-09 설날 대체공휴일과 2027-05-13 부처님오신날은 음력 변환(npm `korean-lunar-calendar`로 계산, 저장소에는 넣지 않음)과 대체공휴일 규정으로 다시 맞춰 봤다. 2027-12-27 성탄절 대체공휴일은 2023년 규정 개정으로 성탄절이 대체 대상에 들어갔다는 기억에 기댄 것이라 아직 확인 필요다. 노동절(5/1)과 제헌절(7/17)은 공휴일 지정 여부가 출처마다 달라 넣지 않았다.
- 2028~2029년 공휴일(2026-11-03 추가)은 웹 검색 요약 [kholidayz 2028](https://kholidayz.com/year/2028), [kholidayz 2029](https://kholidayz.com/year/2029), [달력닷컴 2029 부처님오신날](https://dallyeok.com/holiday/buddha/2029/), [datedb 2028](https://datedb.net/calendar/holidays/2028/)과 음력 변환 계산을 맞춰 봤다. 원문은 세션 네트워크 정책 때문에 열지 못했다. 검색 요약 중 하나는 2028년 추석 대체공휴일을 10/4로 적었는데, 10/4는 이미 추석 연휴라서 규정대로 그다음 날인 10/5로 넣었다.
- 선거일은 공직선거법의 선거일 규칙으로 계산한 추정이다: 2028-04-12 국회의원 선거(임기만료일 2028-05-29 전 50일 이후 첫 수요일), 2030-03-27 대통령 선거(임기만료일 2030-06-03 전 70일 이후 첫 수요일), 2030-06-05 지방선거.
- 2030년은 검색으로 확인하지 못했고 음력 변환과 대체공휴일 규정으로만 계산했다. 2031년부터는 목록 대신 양력 고정 공휴일(신정, 삼일절, 어린이날, 현충일, 광복절, 개천절, 한글날, 성탄절)만 쉬고 설·추석·부처님오신날과 대체공휴일은 빠진다.

## 결과를 해석할 때

- 도구의 효과 중 **시간 절감**은 "사람이 입력하던 필드를 도구가 대신 추출한 개수 × 필드당 입력 시간 − 검토 시간"에서 나옵니다. 필드당 입력 시간 가정이 바뀌면 절감 시간도 비례해서 바뀝니다.
- **오입력 감소**는 도구가 추출에 성공한 필드에서 사람 입력이 사라지기 때문에 생깁니다. 오입력 확률 가정에 비례합니다.
- **잘못된 업체 선택 손실**은 오입력이 업체 순위를 뒤집을 때만 생깁니다. 견적 차이가 크면 오입력이 있어도 선택이 바뀌지 않습니다. 이 손실이 작게 나오는 것은 정상적인 결과일 수 있습니다.

## 출처가 확인된 자료

`docs/practice-sources.md`에 공개 자료 대조 결과를 정리했습니다. 단, 네트워크 제한으로 원문 페이지를 열지 못하고 검색 요약으로만 대조했으므로 잠정 결과입니다. 협상 할인 3~7%는 업계 자료(5~15%, 감사되지 않은 수치)보다 보수적인 값이고, 승인 소요일과 환산 오류 6%는 근거를 찾지 못했습니다.
