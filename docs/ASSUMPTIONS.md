# 가정과 근거 수준

이 시뮬레이션의 수치는 대부분 **가정치**입니다. 실측 자료나 공개 통계에서 가져온 값이 아닙니다.
가정을 숨기지 않고 드러내는 이유는, 도구 효과가 "누가 정한 숫자"인지 설명할 수 있어야 하기 때문입니다.

## 업무 비용 모델 (앱에서 수정 가능)

| 항목 | 기본값 | 근거 수준 | 쓰이는 곳 |
|---|---|---|---|
| 견적서 필드 1개 확인·입력 시간 | 1.2분 | 가정치. 직접 근거 없음 (순수 타이핑은 몇 초 수준이고, 이 값은 찾기와 확인을 포함) | 수작업 견적 입력 시간 |
| 필드 1개 오입력 확률 | 2% | 가정치. 공개 연구 범위(필드별 0.5~6.4%) 안이지만 의료 기록 전사 연구라 분야가 다름 | 단가·납기·결제조건 오입력 |
| 환산 필요 필드 추가 오류 확률 | 6% | 가정치 | USD 환율 착오, VAT·포장단위 착오 |
| 비교표 작성·검토 고정 시간 | 25분 | 가정치 | 견적 비교 1건당 (도구 사용 시 40%) |
| 도구 결과 검토 시간 | 견적 1건당 2.5분 | 가정치 | 도구 사용 시 원문 근거 확인 |
| 정산 불일치 재작업 | 50분 | 가정치 | 발주 단가 오류가 정산에서 발견될 때 |
| 월간 실적 보고 수작업 | 150분 | 가정치 | 월말 보고서 작성 (도구 없음) |
| 보고서 초안 검토·코멘트 | 35분 | 가정치 | 월간 보고 도구 사용 시 |
| 일상 업무(미팅, 문의 대응 등) | 하루 3~6건, 건당 15~90분 | 가정치 | 담당자 업무 부하 |
| 납기 지연 수작업 파악 | 15분 (예정일 당일 미입고를 보고 앎) | 가정치 | 납기 독촉 업무 |
| 납기 위험 알림 확인 | 5분 (예정일 3영업일 전 감지) | 가정치 | 납기 위험 도구 사용 시 |
| 납기 독촉·조율 | 30분, 성공 확률 65%, 남은 시간의 절반까지 만회 | 가정치 | 독촉 결과 입고일 조정 |
| 일일 근무시간 | 480분 | 일반적인 8시간 근무 | 담당자 하루 용량 |

숙련도 보정: 시간은 숙련도 0일 때 1.4배, 100일 때 0.8배. 오류율은 숙련도 0일 때 1.5배, 100일 때 0.5배 (가정치).

## 결과를 해석할 때

- 도구의 효과 중 **시간 절감**은 "사람이 입력하던 필드를 도구가 대신 추출한 개수 × 필드당 입력 시간 − 검토 시간"에서 나옵니다. 필드당 입력 시간 가정이 바뀌면 절감 시간도 비례해서 바뀝니다.
- **오입력 감소**는 도구가 추출에 성공한 필드에서 사람 입력이 사라지기 때문에 생깁니다. 오입력 확률 가정에 비례합니다.
- **잘못된 업체 선택 손실**은 오입력이 업체 순위를 뒤집을 때만 생깁니다. 견적 차이가 크면 오입력이 있어도 선택이 바뀌지 않습니다. 이 손실이 작게 나오는 것은 정상적인 결과일 수 있습니다.

## 출처가 확인된 자료

`docs/practice-sources.md`에 공개 자료 대조 결과를 정리했습니다. 단, 네트워크 제한으로 원문 페이지를 열지 못하고 검색 요약으로만 대조했으므로 잠정 결과입니다. 협상 할인 3~7%는 업계 자료(5~15%, 감사되지 않은 수치)보다 보수적인 값이고, 승인 소요일과 환산 오류 6%는 근거를 찾지 못했습니다.
