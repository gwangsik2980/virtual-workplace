# 구매 업무 흐름 정리 (단계 0)

> 출처 안내: 이 문서는 일반적인 구매 실무 지식을 바탕으로 정리했고, 공개 자료와 대조한 결과를 `docs/practice-sources.md`에 남겼습니다(검색 요약 기준, 원문 미확인). 실무자 검증은 거치지 않았습니다.
> 실무 자료를 확보하면 이 문서를 먼저 고치고, 시뮬레이션 규칙을 맞춰 수정해야 합니다.

## 시뮬레이션의 구매 단계

| 단계 | 담당 | 하는 일 | 시뮬레이션 규칙 |
|---|---|---|---|
| 구매요청(PR) | 생산 → 구매 | 품목·수량·필요일 요청 | 재고+발주 진행분 < 재주문점이면 요청. 남은 재고가 리드타임보다 짧으면 긴급 |
| 시장조사 | 구매 | 시세·환율·수급 확인 | 45분(숙련도 보정). 시작 시점 시장가 기록 |
| 원가분석 | 구매 | 목표가 산정 | 목표가 = (시장가 + 물류비 2.5%) × (1 + 표준마진 3%) |
| 견적요청(RFQ) | 구매 | 같은 조건으로 여러 업체에 요청 | 해당 원료를 취급하는 업체 전부. 회신까지 1~3일(긴급 1일) |
| 견적 비교 | 구매 | 조건 정규화 후 비교 | 수작업 입력 또는 도구. 평가 점수 최저 업체 선정 |
| 단가 협상 | 구매 | 가격 조정 | 할인율 = 업체 여지 × (숙련도, 경쟁 견적 수, 목표가 대비 수준, 운). 긴급이면 협상력 감소 |
| 품의·승인 | 구매 → 팀장 | 선정 근거와 금액 결재 | 3천만 원 초과 2일, 이하 1일. 긴급은 당일 |
| 발주(PO) | 구매 | 발주서 발송 | 발주서 단가는 비교표 입력값 기준이라 오입력이 전파됨 |
| 입고 | 물류·품질 | 입고와 검사 | 납기 신뢰도에 따라 1~4일 지연. 불량률 2% 초과 시 클레임 업무 발생 |
| 검수·정산 | 구매·재무 | 발주·입고·청구 대조 | 발주 단가와 청구 단가가 다르면 재작업 50분 |

## 업체 평가 점수 (견적 비교)

```
점수 = 단가
     − 결제 유예 금융효과 (단가 × 5% × (결제일수 − 30) / 365)
     + 품질 위험 (단가 × 실적 불량률 × 1.5)
     + 납기 위험 (필요일 초과 하루당 단가 × 3%)
     + 신뢰도 위험 (단가 × (1 − 납기 신뢰도) × 5%)
```

가중치는 가정치입니다. 실제 회사는 품목 중요도와 상황에 따라 다르게 정합니다.

## 실무와 다를 수 있는 부분

- 실제로는 기존 계약 단가가 있어 매번 견적을 받지 않는 경우가 많습니다. 여기서는 학습을 위해 매번 견적을 받습니다.
- 협상은 여러 차례 주고받지만 여기서는 한 번의 결과로 요약했습니다.
- 수입 원료의 통관, 선적 일정, 환율 결제 시점은 단순화했습니다.
- 회계는 매출 인식, 매출원가, 재고자산, 채권·채무 시점만 구분하고 세금은 다루지 않습니다.
- 결제조건의 기산점은 실무에서 보통 청구서 발행일이지만, 여기서는 입고일로 단순화했습니다.
- 정산 대조는 단가 차이 0.5%를 허용오차로 쓰고, 수량 차이는 다루지 않습니다.
